## 📌 Project Overview

This project focuses on analyzing student-related data and building machine learning models to **predict students' final academic scores**.

The project follows an end-to-end Data Science workflow, including data cleaning, exploratory data analysis, feature preprocessing, model development, model evaluation, and feature importance analysis.

The final grade (`G3`) is used as the target variable for prediction.

This project was completed as part of a **Data Science Internship – Task 2: Student Performance Prediction**.

---

## 🎯 Project Objectives

The main objectives of this project are:

- Analyze factors affecting student academic performance
- Clean and preprocess the student performance dataset
- Perform exploratory data analysis (EDA)
- Identify relationships between academic and demographic factors
- Build machine learning models to predict final grades
- Compare different regression algorithms
- Evaluate model performance using MAE, RMSE, and R²
- Visualize actual vs predicted grades
- Identify important features using Random Forest
- Save cleaned data and model analysis results

🤖 Machine Learning Models

Three regression algorithms were implemented and compared.

1. Linear Regression

A baseline regression model used to estimate the relationship between student features and final grades.

2. Random Forest Regression

An ensemble machine learning algorithm used to capture nonlinear relationships between student characteristics and final performance.

3. Gradient Boosting Regression

A boosting-based regression algorithm used to improve predictive performance by sequentially learning from previous model errors.

📈 Model Evaluation

The models are evaluated using:

Mean Absolute Error — MAE

Measures the average absolute difference between actual and predicted grades.

Lower MAE indicates smaller prediction errors.

Root Mean Squared Error — RMSE

Measures prediction error while giving greater weight to larger errors.

Lower RMSE indicates better prediction accuracy.

R² Score

Measures how much of the variation in final grades is explained by the model.

Higher R² indicates better explanatory performance.

The actual scores are generated directly from the Jupyter Notebook and should be reported after running the models.
